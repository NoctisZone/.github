## A token launchpad where nobody can see your order

**This project is built on the Midnight Network.**

Everything around the sale is ordinary. Connect a wallet, six steps, and the token
is live on a bonding curve. The sale itself is not.

Midnight lets a contract enforce a rule on data it cannot read. Noctis proves that
no wallet took more than its 5% cap **without ever learning who bought** &mdash; not a
promise never to look, but an inability to.

### What that changes

|  |  |
|---|---|
| **If you buy** | Order amounts stay sealed through the private DarkVeil phase, so nothing can trade ahead of an order it cannot read. |
| **If you launch** | A fair-launch certificate anyone can verify, proving the creator bought nothing and that no wallet breached the cap. Creator fees rise at graduation rather than ending there. |
| **If you hold** | Liquidity locks for a year in a contract with **no withdraw function** &mdash; not disabled, absent. After 90 days of creator silence, holders can vote to take the project over, in a ballot that is itself private. |

Every one of those is a mechanism rather than a policy. Nobody can switch them off,
including us.

### Where a token settles

Midnight is the engine, and the settlement chain is a setting &mdash; the private
phase is the same whichever one a creator picks.

|  |  |
|---|---|
| **Cardano Launch** | The public curve, escrow and LP settle on Cardano L1. The first venue built, and where the concept is proven. |
| **Midnight Launch** | Fully Midnight-native, with Cardano used only to anchor the certificate. In development. |
| **Solana, XRP** | Announced. Each new chain adds settlement contracts; the private phase does not move. |
